# Как опубликована анкета

Анкета работает как веб-приложение Google Apps Script. Ответы каждого участника автоматически добавляются в Google Таблицу (по одной JSON-строке в ячейке столбца A). GitHub Pages не нужен.

1. **Таблица.** Создайте пустую Google Таблицу.
2. **Скрипт.** Откройте script.google.com, создайте проект. В `Code.gs` вставьте `apps_script.gs` (подставьте ID своей таблицы), в `index.html` вставьте `phishing_survey.html`.
3. **Развернуть.** Начать развёртывание → Веб-приложение: «Выполнять от имени» = вы, «Доступ» = все. Скопируйте URL (заканчивается на `/exec`): это ссылка для студентов.
4. **Изменили код?** Нужно создать «Новую версию» в «Управлении развёртываниями», ссылка останется прежней.
5. **Пробный запуск.** Пройдите анкету сами и проверьте, что в таблице появилось 20 строк (2 тренировочных + 18 основных).
6. **Забрать данные.** Скопируйте столбец A в `data/raw/test_run.jsonl`. Конвертировать ничего не нужно.

Если отправка не сработала, на последнем экране есть кнопка «Скопировать ответы» для ручной отправки.
